AI 图片高清化 & 尺寸标准化（macOS 版）使用说明
==========================================

一、选对版本
  - Apple 芯片（M1 / M2 / M3 / M4…）：下载 AIClear-…-macOS-arm64.zip
  - Intel 芯片：下载 AIClear-…-macOS-x64.zip
  不确定时：左上角苹果菜单 →「关于本机」，看「芯片」或「处理器」一栏。
  系统要求：macOS 13.4 Ventura 或更新版本（13.x 的 Mac 在「系统设置 → 通用 → 软件更新」里免费升到最新的 13.7 即可）。

二、第一次启动（只需做一次）
  1. 双击 zip 解压，把得到的 AIClear 文件夹放到「应用程序」或任意位置。
  2. 按住 Control 键点击「Start AIClear.command」，选「打开」，在弹出的提示里再点「打开」。
     （直接双击会提示「无法验证开发者」——本程序未做 Apple 签名，这是正常现象。）
  3. 会打开一个终端窗口，稍等几秒，浏览器自动打开操作页面。
  以后直接双击「Start AIClear.command」即可。

  如果系统仍然阻止：打开「系统设置 → 隐私与安全性」，在下方找到被阻止的项目，点「仍要打开」。

三、使用
  拖入图片 → 勾选 → 设置增强档位、输出尺寸、缩放方式、导出格式 → 开始处理 → 对比 → 下载。
  用完关闭终端窗口即退出。

四、数据存放
  上传的图片和处理结果在：~/Library/Application Support/AIClear/data
  （访达中按 Shift+Command+G，粘贴上面的路径即可打开。）默认保留 30 天。

五、检查程序是否正常
  双击「Run Self-Test.command」（第一次同样按住 Control 点击 →「打开」），
  约 1–3 分钟后显示「自检通过」或「自检失败」，并在本文件夹生成 selftest_report.txt。
  遇到问题时请把这个文件发给技术支持。
