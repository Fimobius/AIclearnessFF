AI 图片高清化 & 尺寸标准化  使用说明
=====================================

一、启动
  1. 把压缩包完整解压到任意文件夹（不要在压缩包里直接双击运行）。
     路径可以有中文和空格。建议放在 D 盘或桌面，不要放在 C:\Program Files。
  2. 双击「Start AIClear.bat」。
  3. 稍等几秒，浏览器会自动打开操作页面。没有自动打开时，手动访问黑色窗口里显示的地址
     （一般是 http://127.0.0.1:8000）。
  4. 用完后关闭黑色窗口即可退出。

  首次运行时 Windows 可能弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
  如果弹出防火墙提示，选「取消」或「允许」都可以（程序只在本机使用，不联网）。

二、使用
  1. 把需要变清晰的图片拖进页面（JPG / PNG / WEBP，可一次拖入很多张）。
  2. 勾选要处理的图片。
  3. 在右侧设置：增强档位、输出尺寸（宽度 + 宽高比）、缩放方式、导出格式。
  4. 点「开始处理」，完成后可对比效果，单张下载或打包下载 ZIP。

三、系统要求
  - Windows 10（1903 及以上）或 Windows 11，64 位
  - 内存 8 GB 以上（推荐 16 GB）
  - 有独立显卡或较新的集成显卡时，会自动用显卡加速（NVIDIA / AMD / Intel 均可）
  - 没有可用显卡时自动用 CPU 处理，速度较慢（每张 1200×1200 约 10–30 秒）
  - 不需要安装 Python 或其他软件，不需要联网

四、数据存放
  上传的图片和处理结果保存在程序目录下的 data 文件夹
  （程序目录不可写时，保存在 %LOCALAPPDATA%\AIClear\data）。
  默认保留 30 天，可以在页面的「历史任务」里随时删除。删除 data 文件夹即清空全部记录。

五、常见问题
  - 浏览器没打开：手动打开黑色窗口里显示的地址。
  - 提示端口被占用：程序会自动换一个端口，以黑色窗口里显示的地址为准。
  - 处理很慢：看页面右上角显示的是「GPU 加速」还是「CPU」。CPU 模式下请减少每批数量或降低输出尺寸。
  - 想在局域网给同事（含 Mac）用：设置环境变量 AICLEAR_HOST=0.0.0.0 和 AICLEAR_API_KEY=你的密钥
    后再启动，详见项目 README。默认只允许本机访问。
